Embed a Remba save button on any site. The control stays on the host page; Remba is only contacted to sign in (if needed) and to add the item to a list.

How it works

  1. Load /embed/remba.js with your app/API settings.
  2. Place a data-remba-save element with either an entity id, a simple JSON item, or plain fields.
  3. Visitors click the R mark → Add to List → + on a list.

Item payload

Prefer data-entity-type + data-id. Remba resolves ISBN, IMDb id, or country code into a proper catalog record. Optional data-id-type forces the identifier kind.

Entity type Default id type Example id
book isbn 9780441172719
film / tv imdbId tt0062622
country iso2 JP
recipe url page URL

Simple JSON schema

Pass data-item='{...}' when you want one attribute. Keep it tiny — only these keys are read: 

{{ '{' }}
  "entityType": "book | film | tv | country | recipe",
  "id": "ISBN / IMDb / ISO2 / URL",
  "idType": "isbn | imdbId | iso2 | url | openLibraryWork",
  "name": "optional display name",
  "author": "optional",
  "director": "optional",
  "link": "optional",
  "imageUrl": "optional",
  "referral": "optional source page URL"
{{ '}' }}
